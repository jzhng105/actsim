\begin{abstract}
\noindent ActSim is a Python-based actuarial simulation package designed for
distribution fitting, stochastic risk modelling, synthetic claim generation, and
actuarial validation and stress testing workflows. It is intended to support actuarial 
risk analysis, catastrophe scenario testing, capital adequacy testing, loss 
scenario analysis, and integration with triangle-based reserving workflows.

\noindent This manual provides a structured reference for users, including a
user guide, worked examples, API reference, validation notes, and contribution
guidance. ActSim emphasises actuarial transparency, reproducibility, and
practical applicability for both research and production environments.
\end{abstract}
